## ⚙️ ขั้นตอนการปฏิบัติงาน (Task Instructions)

### **ตอนที่ 1: การสร้าง LXC Container บน Proxmox**
1. เปิดเว็บเบราว์เซอร์เข้าสู่ Proxmox Web GUI: `https://<IP_เครื่องProxmoxกลุ่ม>:8006`
2. คลิกปุ่มสีฟ้า **`Create CT`** ที่มุมบนขวา และกำหนดค่าดังนี้:
   - **CT ID:** `100 + เลขที่ของนักศึกษา` (เช่น เลขที่ 5 ใช้ ID `105`)
   - **Hostname:** `std<เลขที่>-webserver` (เช่น `std05-webserver`)
   - **Password:** กำหนดรหัสผ่าน root สำหรับตู้ของตนเอง (จำรหัสผ่านนี้ไว้ให้ดี)
   - **Template:** เลือก `ubuntu-22.04-standard`
   - **Disk Size:** `10 GiB` หรือ `15 GiB`
   - **CPU:** `1 Core`
   - **Memory:** `512 MB` หรือ `1024 MB` (Swap: `512 MB`)
   - **Network:** Bridge: `vmbr0`, IPv4 เลือก `Static` กำหนด IP ประจำตัว (เช่น `192.168.1.105/24`) และ Gateway: `192.168.1.1`
3. คลิกปุ่ม **Finish** และสั่ง **Start** ตู้ Container จนไอคอนเปลี่ยนเป็นสถานะสีเขียว (Running)

---

### **ตอนที่ 2: การเข้าควบคุมผ่าน SSH และติดตั้ง Nginx**
1. เปิดโปรแกรม Terminal / PowerShell บนคอมพิวเตอร์ของตนเอง แล้วพิมพ์คำสั่ง SSH:
   ```bash
   ssh root@<IP_ตู้ของตนเอง>
   ```
2. ทำการอัปเดตระบบและติดตั้ง Nginx Web Server:
   ```bash
   apt update && apt upgrade -y
   apt install -y nginx curl nano
   ```
3. แก้ไขไฟล์หน้าเว็บเริ่มต้น (`/var/www/html/index.html`):
   ```bash
   nano /var/www/html/index.html
   ```
   *แก้ไขเนื้อหา HTML ให้แสดงข้อมูลดังนี้:*
   - **ชื่อ-นามสกุล และ รหัสนักศึกษา**
   - **เลขที่ และ กลุ่มเรียน**
   - **หมายเลข IP Address และ Hostname ของตู้ตนเอง**
   *(บันทึกไฟล์ด้วยการกด `Ctrl+O` -> `Enter` และออกด้วย `Ctrl+X`)*
4. ตรวจสอบสถานะการทำงานของ Nginx:
   ```bash
   systemctl status nginx
   ```
5. เปิดเว็บเบราว์เซอร์แล้วพิมพ์ URL: `http://<IP_ตู้ของตนเอง>` เพื่อทดสอบเปิดดูหน้าเว็บ

ให้นักศึกษาบันทึกภาพหน้าจอ (Screenshot) ให้เห็นข้อมูลชัดเจน 4 ภาพ ดังนี้:
- [ ] **ภาพที่ 1 (Proxmox Dashboard):** หน้าเว็บ Proxmox ที่แสดงตู้ Container ของตนเองสถานะสีเขียว (Running) พร้อมเห็นสเปก CPU, RAM และ IP Address

## ✍️ คำถามท้ายบทเรียน (ตอบสั้นๆ 2-3 บรรทัดต่อข้อ)

**คำถามข้อที่ 1 (Network):**  
ในการตั้งค่าระบบเครือข่ายของ LXC Container การเลือกแบบ **"Static IP"** ต่างจาก **"DHCP"** อย่างไร? และทำไมเครื่องที่เป็น 'เซิร์ฟเวอร์' ถึงควรตั้งค่าเป็น Static IP?

**คำถามข้อที่ 2 (Architecture):**  
LXC Container มีการ **"แชร์ Linux Kernel ร่วมกับเครื่องแม่ (Host)"** อยากทราบว่ามีข้อดีอย่างไร? และเราสามารถสร้างตู้ที่เป็นระบบปฏิบัติการ Windows บน LXC ได้หรือไม่ เพราะอะไร?

**คำถามข้อที่ 3 (OS Template):**  
ในการสร้างตู้ Container บน Proxmox เราจะใช้ไฟล์ **'OS Template'** (เช่น `ubuntu-22.04.tar.zst`) แทนที่จะใช้ไฟล์แผ่นติดตั้งแบบ ISO อยากทราบว่าการสร้างเครื่องจาก Template มีข้อดีอย่างไร และช่วยประหยัดเวลาได้อย่างไรบ้าง?

**คำถามข้อที่ 4 (Resource Management):**  
ถ้าวันหนึ่งตู้ Container ของเราเกิด **"แรมไม่พอ"** (เช่น เดิมตั้งไว้ 512MB แล้วต้องการเพิ่มเป็น 1GB หรือ 2GB) บน Proxmox เราสามารถเข้าไปกดแก้ไขได้ที่เมนูใด? และวิธีนี้สะดวกกว่าการเดินไปเพิ่มแรมบนเครื่องคอมพิวเตอร์จริงอย่างไรบ้าง?

# 💡 [ส่วนของอาจารย์] แนวคำตอบสำหรับตรวจให้คะแนน (Answer Key)

### **เฉลยข้อที่ 1:**
- **ความต่าง:** `DHCP` คือการรับ IP อัตโนมัติซึ่งอาจเปลี่ยนเลขได้เมื่อรีบูต ส่วน `Static IP` คือการกำหนดเลข IP คงที่แน่นอนถาวร
- **เหตุผลที่เซิร์ฟเวอร์ต้องใช้ Static IP:** เพราะเครื่องเซิร์ฟเวอร์ต้องให้บริการตลอดเวลา หาก IP เปลี่ยนจะทำให้ผู้ใช้งานหรือระบบอื่นเชื่อมต่อเข้ามาไม่ถูกที่ และไม่สามารถผูกชื่อโดเมน (DNS) ได้อย่างถูกต้อง

### **เฉลยข้อที่ 2:**
- **ข้อดี:** ประหยัดทรัพยากร CPU/RAM มหาศาล และบูตเครื่องได้รวดเร็วมากใน 1-2 วินาที
- **การรัน Windows:** **ไม่สามารถรันได้** เพราะ LXC ใช้ Kernel ร่วมกับ Linux Host เท่านั้น หากต้องการรัน Windows ต้องสร้างเป็น `KVM Virtual Machine (VM)` แทน

### **เฉลยข้อที่ 3:**
- **ข้อดีของ OS Template:** Template คือระบบปฏิบัติการที่เตรียมไฟล์ระบบและบีบอัดไว้พร้อมใช้แล้ว เมื่อกดสร้าง Proxmox แค่แตกไฟล์ออกมาทำให้พร้อมรันได้ในไม่กี่วินาที ไม่ต้องเสียเวลาบูตแผ่น ISO และไม่ต้องกด Setup ทีละขั้นตอนเหมือนการลง OS ทั่วไป

### **เฉลยข้อที่ 4:**
- **เมนูที่ใช้แก้ไข:** ไปที่ตู้ Container ของเรา -> คลิกแถบ **Resources** -> ดับเบิ้ลคลิกที่ **Memory** แล้วแก้ไขตัวเลขเป็น 1024MB ได้ทันที
- **ความสะดวก:** ปรับแต่งเสร็จได้ในไม่กี่คลิกผ่านหน้าเว็บ Proxmox ได้ทันที ไม่ต้องรื้อแกะฝาเคสคอมพิวเตอร์ ไม่ต้องซื้อฮาร์ดแวร์แรมจริงมาเสียบ และไม่ต้องเสียเวลาดับเครื่อง
