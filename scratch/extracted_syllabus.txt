ส่วนที่ 1: ข้อมูลรายวิชา
ผลลัพธ์การเรียนรู้ระดับรายวิชา
ติดตั้งและสนับสนุนด้านเทคนิค เพื่อการใช้งานคอมพิวเตอร์แม่ข่ายด้านระบบสารสนเทศและระบบเครือข่ายตามหลักการ ด้วยความละเอียดรอบคอบ รับผิดชอบ การสื่อสาร การคิดเชิงนวัตกรรมและการทำงานเป็นทีม
จุดประสงค์รายวิชา
1. เข้าใจโมเดล OSI 7 Layer, TCP/IP และหลักการทำงานของเครือข่ายคอมพิวเตอร์พื้นฐาน
2. เข้าใจเกี่ยวกับการติดตั้ง การใช้งานระบบปฏิบัติการเครื่องแม่ข่ายและแพ็กเก็ต (Packet) ที่สนับสนุนการให้บริการในระบบเครือข่าย
3. มีทักษะในการติดตั้งและบริหารจัดการ Proxmox Hypervisor และ Virtual Machine (VM)
4. มีทักษะในการติดตั้ง Server บริการต่าง ๆ เช่น DNS, Web, Database, DHCP, File, Proxy, AAA, Container
5. สามารถ Deploy Web Application ลงบน VM ด้วยแนวคิด DevOps เบื้องต้น
6. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความละเอียดรอบคอบ รับผิดชอบ
สมรรถนะรายวิชา
1. อธิบายหลักการทำงานของโมเดล OSI 7 Layer และ TCP/IP Protocol ได้
2. ติดตั้งระบบปฏิบัติการเครื่องแม่ข่ายและแพ็กเก็ต (Packet) ที่สนับสนุนการให้บริการในระบบเครือข่ายตามขั้นตอน
3. ติดตั้งและบริหารจัดการ Proxmox VE Hypervisor พร้อมสร้าง VM ได้
4. ให้บริการ Server (DNS, Web, DB, DHCP, File, Proxy, AAA, Container) ได้ครบถ้วน
5. Deploy Web Application บน VM ด้วย Docker และแนวคิด DevOps ได้
6. ใช้งานระบบปฏิบัติการเครื่องแม่ข่ายตรงตามวัตถุประสงค์
คำอธิบายรายวิชา
ศึกษาและปฏิบัติเกี่ยวกับ โมเดล OSI 7 Layer และ TCP/IP Protocol, ระบบปฏิบัติการบนเครื่องแม่ข่าย (Network Operating System), การเข้าหัวสาย LAN ตามมาตรฐาน TIA/EIA, การติดตั้ง Proxmox Hypervisor, การสร้างและจัดการ Virtual Machine (VM), การตั้งค่าพื้นฐาน, การจัดการผู้ใช้งาน, Firewall, SSH, DNS Server, Web Server, Database Server, DHCP Server, File and Resource Sharing Server, Proxy Server, AAA Server, Container Platform (Docker), IoT Platform, SSL Certificate และการ Deploy Web Application ด้วยแนวคิด DevOps เบื้องต้น

มาตรฐานอาชีพ
รหัส 40106 ช่างสนับสนุนด้านเทคนิค ระดับ 5
1. ผลลัพธ์การเรียนรู้ระดับหน่วยการเรียน
• ผู้เรียนสามารถอธิบายหน้าที่ของแต่ละ Layer ใน OSI 7 Layer Model ได้ถูกต้อง
• ผู้เรียนสามารถเปรียบเทียบ OSI Model กับ TCP/IP Model ได้
• ผู้เรียนสามารถระบุ Protocol ที่ทำงานในแต่ละ Layer ได้อย่างน้อย 3 ตัวอย่าง
• ผู้เรียนสามารถวิเคราะห์ Packet ด้วย Wireshark และระบุ Layer ที่เกี่ยวข้องได้
2. อ้างอิงมาตรฐาน / เชื่อมโยงกลุ่มอาชีพ
2.1 มาตรฐานอาชีพ: รหัส 40106 ช่างสนับสนุนด้านเทคนิค ระดับ 5
     เกณฑ์: อธิบายโครงสร้างเครือข่ายและ Protocol ที่เกี่ยวข้องได้
2.2 บูรณาการกลุ่มอาชีพ: Network Administrator / IT Support / System Administrator
3. สมรรถนะประจำหน่วย
• อธิบาย OSI 7 Layer และหน้าที่แต่ละชั้นได้
• ระบุ Protocol สำคัญ (HTTP, FTP, DNS, TCP, UDP, IP, Ethernet) ในแต่ละ Layer ได้
• เปรียบเทียบ OSI กับ TCP/IP Model ได้
• ใช้ Wireshark จับและวิเคราะห์ Packet ได้
4. จุดประสงค์เชิงพฤติกรรม
• อธิบาย OSI 7 Layer ครบทุก Layer
• ระบุ Protocol ที่ทำงานในแต่ละ Layer ได้อย่างน้อย 2 ตัวอย่างต่อ Layer
• เปรียบเทียบ OSI กับ TCP/IP ได้อย่างชัดเจน
• ใช้ Wireshark ดู Packet และระบุ Layer ที่เกี่ยวข้องได้
• แสดงความกระตือรือร้นและตั้งคำถามในชั้นเรียน
5. สาระการเรียนรู้
• OSI 7 Layer: Physical, Data Link, Network, Transport, Session, Presentation, Application
• หน้าที่แต่ละ Layer และอุปกรณ์ที่เกี่ยวข้อง (Hub, Switch, Router, Firewall)
• Protocol สำคัญ: HTTP/HTTPS, FTP, SMTP, DNS, TCP, UDP, IP, ICMP, ARP, Ethernet
• การ Encapsulation / Decapsulation ของ Data
• TCP/IP Model: Network Access, Internet, Transport, Application
• การเปรียบเทียบ OSI vs TCP/IP

• ผู้เรียนสามารถอธิบาย SSH Protocol และ Key-based Authentication ได้
• ผู้เรียนสามารถสร้าง SSH Key Pair และเชื่อมต่อ Server ด้วย SSH Key ได้
• ผู้เรียนสามารถ Harden SSH Server (Disable Password Login, Change Port) ได้
• ผู้เรียนสามารถใช้ scp และ rsync โอนไฟล์ผ่าน SSH ได้

• อธิบาย SSH Protocol และ Public Key Cryptography ได้
• สร้าง SSH Key Pair (RSA/ED25519) ได้
• Harden SSH ตามมาตรฐานความปลอดภัยได้
4. จุดประสงค์เชิงพฤติกรรม
• เปิด OpenSSH-server บน VM ได้
• สร้าง SSH Key ด้วย ssh-keygen ได้
• Copy Public Key ด้วย ssh-copy-id ได้
• แก้ไข /etc/ssh/sshd_config เพื่อ Harden ได้
• ใช้ scp โอนไฟล์ได้
5. สาระการเรียนรู้
• SSH Protocol: Port 22, Symmetric/Asymmetric Encryption
• SSH Key: RSA vs ED25519, Public/Private Key
• OpenSSH: Installation, Configuration (/etc/ssh/sshd_config)
• SSH Hardening: PasswordAuthentication no, PermitRootLogin no
• File Transfer: scp, rsync, SFTP
• SSH Config File (~/.ssh/config)
